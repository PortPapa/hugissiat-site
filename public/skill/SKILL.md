# 후기씨앗 글쓰기 (hugissiat-writer)

사용자는 **작성 가이드만** 준다. 나머지는 이 스킬이 한다.
내용은 사용자가 후기씨앗 앱에 남긴 **실제 경험과 사진만** 쓴다. 디자인과 말투는 **style.md**를 따른다.
결과는 네이버 블로그 **임시저장까지만**. 발행 버튼은 절대 누르지 않는다.

## 파일
- `style.md`: 내 블로그 스타일. hugissiat.com에서 등록할 때마다 새로 저장된다. 매번 새로 읽는다.
- `hs-naver.js`: 스마트에디터 입력 도우미. REPL에서 읽어 `eval`한 뒤 `makeHS(page, style)`로 쓴다.
- 드라이브: 이 스킬은 `후기씨앗 / 글쓰기 스킬 /`에 있다. 경험 기록은 `후기씨앗 / YYYY년 M월 / DD 업체명 /` 안에 `YYYY-MM-DD 업체명.md`(또는 `후기 소스.md`)와 사진(`... 01.jpg` 순서).

## 순서

### 1. 가이드 읽기 → 체크리스트
가이드(텍스트, 링크, 캡처 무엇이든)에서 아래를 뽑아 표로 정리한다. 없는 항목은 "없음".
- 업체·제품명, 방문(사용)일, 마감일
- 제목 규칙 (필수 단어, 글자 수)
- 필수 키워드와 횟수, 태그
- 꼭 들어가야 할 내용 (메뉴, 시설, 이벤트 등)
- 사진 최소 장수, 동영상, 지도(장소) 첨부, 링크 첨부
- 대가 표기 문구와 위치 (문구는 **그대로** 쓴다)
- 금지 표현, 기타 요청

### 2. 내 기록과 사진 찾기
구글 드라이브(사용자가 후기씨앗 앱에 연결한 계정)의 `후기씨앗` 폴더에서 업체명·날짜로 폴더를 찾는다.
- MD를 읽고, 사진을 순서대로 내려받는다(임시 폴더).
- 못 찾거나 후보가 여럿이면 사용자에게 고르게 한다.
- **가이드가 요구하는데 기록에 없는 내용**(예: 주차, 특정 메뉴 맛)이 있으면 쓰기 전에 한 번에 모아서 짧게 묻는다. 절대 지어내지 않는다.

### 3. 스타일 읽기
`style.md`의 디자인 값(JSON)과 말투 메모를 읽는다. 참고 글 URL이 있으면 2~3편을 열어 문장 길이·끝맺음·이모지 습관을 확인한다.

### 4. 구성 정하기
- 가이드 필수 항목이 빠짐없이 들어가는 순서로 소제목을 잡는다.
- 메인 키워드로 `https://hugissiat.com/api/top?q=키워드`를 불러 상위 글 평균(사진 수, 글자 수, 소제목 수, 지도 비율)을 목표치로 삼는다. 글자 수는 가이드 기준과 상위 평균의 80% 중 큰 값.
- 기본 흐름: 대표 사진 → (대가 표기, style.notice가 top이면) → 인사·방문 이유 → 요약(선택) → 소제목 × N (사진 묶음 + 짧은 문단) → 아쉬운 점·팁 → 정보 표 → 지도 → 마무리.

### 5. 쓰기 규칙
- 기록에 있는 사실만. 숫자·가격·시간은 기록 그대로.
- style의 끝맺음을 섞어 쓴다. 같은 어미를 세 줄 연속 쓰지 않는다. "~었어요" 반복 금지.
- 한 줄 25~40자, 2~3줄마다 빈 줄.
- 키워드는 제목 1회 + 본문에 자연스럽게 가이드 횟수만큼. 키워드만 나열한 문장 금지.
- 포인트 글자색은 숫자·메뉴명·키워드에만, 형광펜은 글 전체에서 1~2문장.
- AI 티 나는 표현 금지: "~에 대해 알아보겠습니다", "결론적으로", "다양한", "완벽한", 과한 감탄.

### 6. 에디터에 넣기
```js
const code = await fs.readFile('<이 스킬 폴더>/hs-naver.js', 'utf8'); (0, eval)(code);
const P = await openTab(`https://blog.naver.com/${style.blogId}?Redirect=Write`);   // 에디터 탭은 하나만
const H = makeHS(P, style);
await H.open();            // 'DIALOG'면 작성 중인 글 안내: 사용자 글일 수 있으니 확인 후 진행
await H.title('제목');
await H.run(blocks);       // 블록 배열 (아래)
await H.save();            // 임시저장. 발행 금지
```
블록: `{img:'파일경로'}` `{p:['줄','', '줄']}` `{sub:'소제목'}` `{quote:'한 문장', l:'quotation_bubble'}` `{summary:['줄','줄']}` `{hr:1}` `{table:[['항목','내용'],['주소','...']]}` `{place:'업체명 지점'}` `{notice:'대가 표기 문구'}`
- 문단 안 강조: `H.c('포인트')`, `H.m('형광펜 문장')`, `H.b('굵게')`를 문자열 안에 넣는다. 형광펜은 **문단 중간**에 넣고 그 문단은 일반 문장으로 끝낸다(서식 번짐 방지).
- 사진은 기록 사진을 모두 쓰되, 소제목마다 2~3장씩 나눈다.

### 7. 마무리 보고
임시저장 후 아래를 사용자에게 보여준다.
- 제목, 글자 수, 사진 수
- 가이드 체크리스트 (✔/✘), 빠진 것은 이유
- 에디터 화면 캡처 1~2장
발행은 사용자가 직접 한다고 한 번 더 알린다.

## 주의
- 에디터 탭은 하나만 연다. 두 개면 입력이 사라진다.
- "작성 중인 글이 있습니다" 창에서 취소는 자동저장본을 지운다. 사용자 글일 수 있으면 먼저 묻는다.
- 같은 제목 임시저장은 덮어써질 수 있다. 저장 후 임시저장 개수를 확인한다.
- 사진에 사람 얼굴·차 번호판이 보이면 사용자에게 알린다.
